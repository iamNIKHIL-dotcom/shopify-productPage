
# Shopify Product Landing Page

## Overview
This project is a **Shopify product landing page** built with **HTML**, **CSS**, and **JavaScript**. It is fully responsive, ensuring optimal user experience across various screen sizes and devices. The landing page showcases a product with dynamic features like interactive price changes based on size selection.

## Features
- **Dynamic Price Updates**: Prices change seamlessly as users select different product sizes.
- **Responsive Design**: The page adapts to different devices (mobile, tablet, and desktop).
- **Interactive UI**: A modal size chart is implemented for user convenience.
- **Custom Styling**: Includes vibrant and modern design elements for better user engagement.

## Technologies Used
- **HTML**: Structure and semantics of the page.
- **CSS**: Styling and responsive design.
- **JavaScript**: Functionality for interactivity.
